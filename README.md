## 📂 Featured Projects

- Implemented stochastic simulation models demonstrating entanglement advantage in the single-shot regime.
- Utilized surrogate-based hyperparameter optimization (BOHB + active learning) to improve predictive accuracy (NRMSE) by 35%.

- Architected autonomous AI agents (Google Gemini, LangGraph) to parse complex tax forms (W-4, W-2, TD1) and orchestrate database syncs.
- Integrated Plaid, Modern Treasury, and QuickBooks Online APIs for secure financial workflows.

### [⚡ GridSense — GenQ Global Hackathon Winner (2025)](https://github.com/alikauc)

- Combined brain-inspired quantum modeling with classical pipeline components, securing First Place overall.
